# AI 功能纪律（ai-feature）

dev-process 阶段 0.5 的触发加载项。凡模型参与的链路，以下不变量对正式能力、联调工具、"临时"功能一视同仁——"临时"是范围属性，不是纪律豁免（源 §2.1）。badcase 证据查 `../dev-process/references/开发过程经验蒸馏.md` §7。

## 1. 目的与边界

**做**：AI 链路的结构纪律与检查清单。
**不做**：通用开发流程（dev-process）、模型选型与提示词效果调优方法论、业务规则定义。

## 2. 触发条件

- 链路含模型输出（对话 / 抽取 / 解析 / 生成 / 工具调用）；
- 新增或修改由模型输出触发的确定性校验；
- 新增或修改流式输出接口（SSE / WebSocket / 分块响应）；
- 接入、更换或升级厂商 SDK / 适配器。

## 3. 不变量

### 3.1 模型输出只产生候选（源 §2.1）

模型可以准备操作，但不能直接写业务状态。四层分离：**候选输出 → 已接受的不可变结果 → 业务状态 → 系统失败**。写入前必须完成确定性校验 + 授权 + 短事务提交。身份、权限、金额终值、业务状态是确定性边界——模型不得直接产出终值。

检查：

- 校验逻辑写成纯函数，便于独立测试；
- 契约测试覆盖"候选不合格时业务状态不变"；
- 数据库、模型或工具失败不得伪装成成功；提交前不得向客户端流式发送成功表述。

### 3.2 校验门槛必须对模型可见——四连动（源 §2.2）

新增/修改任何由模型输出触发的确定性校验，必须**同步四处**，任何一处缺失 = 未完成：

1. 校验代码本身；
2. 系统提示词 / 工具描述 / 返回协议（模型看得见的"说明书"）；
3. 可修复错误反馈（告诉模型哪里不合格、怎么改，不是裸错误码）；
4. 回归测试。

禁止服务端执行模型不可见的新门槛——那会产生无效重试循环。

### 3.3 无 AI 冒烟主干（源 §2.3）

业务主干打通后立即固化一条**零 AI** 的端到端冒烟：走 stub 适配器路径、逐步 PASS/FAIL 输出、可重复、可清理数据。模型链路单独显式启用，不混入普通回归。AI 故障不得淹没结构性回归，契约验证不依赖模型方差。

### 3.4 工具状态与仓库事实分离（源 §2.4）

AI 工具的会话状态、记忆、缓存一律不入库；有价值的结论整理进正式文档目录后才算仓库事实；ignore 清单初始化时把工具状态目录列全。

### 3.5 流式契约按事件通道设计（源 §2.5）

- 事件枚举各自独立，定义各自负载形状：思考链增量（reasoning）/ 正文增量（content）/ 结构化结果（candidate）/ 错误（error）；前端按事件类型分别渲染，连接中断、解析失败与业务失败不分通道就无法分别处理；
- 厂商可选能力（如思考链）通过特征参数请求；"参数被拒"（如 400）做**自动降级重发**（关闭该参数重试），不整体失败；
- **"流完了" ≠ "校验过了"**：流式终点必须接既有确定性校验与候选/接受落库链路。
- **流终点必须显式结束标记（源 §2.5，2026-11 实测新增）**：在 final 事件前发送约定终止标记（如 `event: done` + `data: [DONE]`），客户端以它为唯一可靠的退出信号——传输层关闭不可依赖：dev 代理（vite http-proxy）、部分网关/缓冲层不向上游转发 SSE close，客户端 reader 永不 done，表现为"流式内容正常显示但会话永久 busy、第二条消息发不出"。注意两个陷阱：① 标记检查必须在**事件处理循环内**完成（`buf.split('\n\n')` 后残余检查永远匹配不到已处理块）；② 错误路径（error 事件）同样要带终止标记再 close，否则失败场景挂死。**录制/演示前置检查**：手动发第二条消息验证流真正释放。

### 3.6 厂商适配与降级（源 §4.5、§7）

- 外部模型走端口 + 适配器；官方 SDK 优先，无官方 SDK 时在适配器内直连官方 HTTP 并记录依据；
- 每次接入跑一条最小链路验证，含每条降级路径；
- 模型调用日志可审计：候选与接受两层落库（调用入参、思考内容、结构化结果均可回放追溯）。

## 4. 完成检查

- [ ] 四层分离成立，契约测试含"候选不合格时业务状态不变"；
- [ ] 每条确定性校验可逐处指认四连动（提示词/工具描述位置、错误反馈文案、回归测试）；
- [ ] 无 AI 冒烟可跑且绿；
- [ ] 流式事件通道有枚举与负载形状定义；每个厂商可选参数有降级路径测试；
- [ ] 流终点有显式结束标记（[DONE] 类），且错误路径同样携带；客户端已在事件循环内识别该标记（用多轮对话验证第二条消息可发）；
- [ ] 流式终点接确定性校验与落库链路；
- [ ] AI 工具状态未入库；
- [ ] 模型调用日志可审计（候选/接受两层）。
